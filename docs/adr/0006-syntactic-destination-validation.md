# Destination validation is syntactic

Creating a Short Link rejects Destinations that are not public web URLs — non-http(s) schemes, `localhost` and `*.localhost` hosts, private/loopback/link-local IP literals, and values over 2048 characters — but the checks are purely syntactic: the host is inspected as written and never DNS-resolved at creation. Resolving would turn every creation into a network call (latency, a resolver dependency, and a signal an abuser can probe) and would still not close the gap — a public DNS name can point at a private address an hour after the check. The posture matches the rest of the abuse story: attribute every Short Link to a keyholder (#4), count Clicks (#5), Deactivate on confirmed reports (#6), rate-limit per key (#7); existing links are never revalidated. The accepted cost is a residual syntactic gap — exotic IPv4 notations (hex or short forms like `0x7f.1` and `127.1`), and public hostnames that resolve into private networks — deferred until real abuse asks for more.

# Short Link Destinations are immutable

A Short Link's Destination is fixed at creation; there is no edit feature, and fixing a typo means creating a new link. Editing is the standard feature users expect, but on a public service it is the textbook abuse pattern — share a benign link, let it spread, then retarget it to phishing — and immutability kills that vector entirely. Adding editing later is additive; removing it after launch would break user trust.
